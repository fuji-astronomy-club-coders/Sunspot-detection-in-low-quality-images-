# pyproject-template

This is a template for Python project repositories, intended for use by team members.

このテンプレートを使用する方法の詳細は、tutorialフォルダを参照してください。
なお、本リポジトリは`Require a pull request`を有効にしているため、`pull-request-manual`を参照しながら開発を行ってください。

tutorial

- `tutorial\manual.md` : このテンプレートを使用する際のマニュアル
- `tutorial\pull-request-manual.md` : 開発を行う際のマニュアル
- `tutorial\vscode-setup.md` : VScodeの拡張機能の設定
- `tutorial\env-setup.md` : pythonの仮想環境などの環境構築マニュアル

## Windowsでの起動

Windowsでは、プロジェクトルートの `run.bat` から起動できます。

```bat
run.bat
```

通常起動ではPATH上のPythonを使用し、仮想環境は新規作成しません。Python 3.13以上が必要で、`pyproject.toml` の依存パッケージは起動時にインストールされます。

仮想環境を使用する場合は、次のいずれかを指定します。

```bat
run.bat --venv
run.bat -v
```

この場合のみ、プロジェクトルートの `.venv` を作成または再利用します。詳細は [総合利用説明書](docs/user_guide.md) を参照してください。

依存パッケージを事前に用意したPython環境から直接起動する場合は、従来どおり `python run.py` も使用できます。

## 実行結果・ログの保存先

アプリケーションを `run.bat`（Windows）または `python run.py` で実行すると、設定ファイルの内容と実行環境を含むログが自動的に保存されます。

- 保存先: `Paths.output_folder/session_YYYYMMDD_HHMMSS_xxxxxx/`
- セッションフォルダー直下に、周縁減光補正・強調・抽出の各画像を保存
- 強調画像はマスク適用前の画像（従来のファイル名）と、選択したマスク領域を0で除外した画像（ファイル名末尾が `_masked.png`）の両方を保存
- サマリー画像と `.log`・`.json` の実行ログも同じ階層に保存
- セッション内に用途別のサブフォルダーは作成しません

ログには実行開始・終了時刻、処理時間、実行スクリプトと引数、作業ディレクトリ、OS・CPUアーキテクチャ、Python情報、主要依存パッケージのバージョン、実際に使用した設定、検出数、解析中のデバッグ情報を記録します。`sunspot` ロガー経由のログはセッション `.log` ファイルに保存すると同時にターミナルにも出力します。ターミナルは `INFO` 以上に絞り、処理の進捗・集計・警告・エラーを表示します。個々の黒点候補の座標や再検討内容などの `DEBUG` 詳細ログはターミナルには表示せず、`.log` ファイルにのみ記録します。ファイルログは `DEBUG` 以上を保存します。 入力画像のメタデータも `input_image_metadata` イベントとして `.log` と `.json` に保存します。基本情報（ファイルパス・形式・容量・更新日時、画像配列の形状・データ型・画素数）に加え、TIFF はシリーズ情報・ページ情報・タグ・ImageJ/OME メタデータ、FITS は各 HDU のヘッダー項目（値とコメント）を記録します。TIFF のページ別タグは先頭32ページ分を記録し、残りのページ数も明記します。画素データそのものはログに保存しません。処理に失敗した場合は、例外の種類・メッセージ・スタックトレースも記録します。設定キーおよびコマンドライン引数内の `password`、`token`、`secret`、`api-key` などに該当する値はマスキングします。環境変数の値は記録しません。1回の実行で生成される画像・サマリー・ログはすべて同じセッションフォルダー直下に保存され、セッション内にサブフォルダーは作成されません。マスク処理では、選択した各 ROI の座標 `(x, y, width, height)`、画像サイズ、範囲のピクセル面積、画像全体に占める割合、領域ごとの重複候補数、マスク適用前後の候補数、除外した候補ラベルをイベントとして追記します。


### 黒点統計 CSV と最終確認画面

各セッションフォルダーに `sunspot_statistics.csv` と `sunspot_exclusion_list.csv` を出力します。`sunspot_statistics.csv` にはマスク適用後に残った黒点のラベル、重心座標、外接矩形の左上座標・幅・高さ、画素面積を記録します。`sunspot_exclusion_list.csv` にはマスクで除外された黒点について同じ幾何情報に加え、除外元のマスク番号と各マスクの座標・大きさを記録します。複数のマスクに重なった黒点は、該当するすべてのマスクを記録します。座標は画像左上を原点とした0始まりのピクセル座標です。

CSV の列名・値の意味・座標系・複数マスクに重なった場合の見方は [`docs/csv_output_guide.md`](docs/csv_output_guide.md) を参照してください。

最終解析画像の対話的な確認は `Display.show_final_image: true` で有効化でき、PyQt ダイアログで表示します。


### 画像確認ダイアログの操作

最終解析画像の確認ダイアログは、Matplotlib のナビゲーションツールバーに近い構成です。

- **Home** または Home キー: 画像全体が収まる表示へ戻します。
- **Back／Forward**: 直前・直後の表示範囲へ移動します。
- **Ctrl + マウスホイール**: カーソル位置を中心に拡大・縮小します。
- **Zoom** を選択して左ドラッグ: 囲んだ範囲を拡大します。
- **Pan** を選択して左ドラッグ: 表示位置を移動します。
- **Shift + 右ドラッグ**: Pan モードを選ばずに表示位置を移動します。
- ダイアログ下部にはカーソル位置と現在の X・Y 表示範囲を表示します。

マスク選択ダイアログには、画像の表示に使用したカラーマップと画素値の最小値・最大値を示すカラーバーを表示します。最終確認画面では、チェックマーク付きの **Mask Fill** と **無効黒点** のチェックボックスで、それぞれマスク範囲の半透明塗りつぶしと、マスクで除外された黒点（赤色オーバーレイ）の表示を切り替えられます。初期状態は `Display.show_mask_fill` と `Display.show_invalid_sunspots` で設定します。塗りつぶしの色と不透明度は `Display.mask_fill_color` と `Display.mask_fill_alpha` で設定します。
