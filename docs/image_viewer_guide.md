# 画像確認ダイアログの操作ガイド

## 最終解析画像

最終解析画像の確認ダイアログは、Matplotlib のナビゲーションツールバーを使う利用者が迷わないよう、Home・Pan・Zoom を上部に配置しています。

| 操作 | 動作 |
| --- | --- |
| Home ボタン / Home キー | 画像全体が収まる初期表示へ戻す |
| Back / Forward | 直前・直後の表示範囲へ移動 |
| Ctrl + マウスホイール | カーソル位置を中心に拡大・縮小 |
| Zoom を選択して左ドラッグ | ドラッグした矩形の範囲へ拡大 |
| Pan を選択して左ドラッグ | 表示位置を移動 |
| Shift + 右ドラッグ | ツール選択状態に関係なく表示位置を移動 |

ダイアログ下部の HUD には、カーソル位置（画像ピクセル座標）・その画素の輝度値・現在の X・Y 表示範囲が表示されます。輝度値はカラーマップ適用前の元画像配列から取得するため、表示用の色変換や正規化の影響を受けません。整数画像は整数値、浮動小数点画像は元配列の値を表示します。画像はマスク選択画面と同じ向きで表示し、座標は画像左上を原点とする0始まりのピクセル座標で扱います。ズーム・パン・マスク範囲の描画もこの座標系に統一しています。表示範囲を変更しても、画像の縦横比は維持されます。

## マスク範囲の塗りつぶし

マスク選択ダイアログでは、画像の右側にカラーバーを表示します。カラーバーは選択したカラーマップ（`MaskDialog.display.colormap`）と同じ色変化を示し、上端に画素値の最大値、下端に最小値を表示します。選択方式が `rectangle` の場合は矩形選択、`connected_component` の場合は連結成分のクリック選択に使用します。

選択したマスク範囲の半透明塗りつぶしは、**最終解析画像の確認ダイアログ**に重ねて表示します。rectangle方式では矩形を、connected_component方式では選択した連結成分の輪郭形状を表示します。表示はズーム・パンに追従し、マスク選択画面と同じ左上原点の座標で描画します。画像データやマスク処理の結果は変更しません。

`src/config.yaml` の `Display` で設定します。

- `show_mask_fill`: 塗りつぶし表示の有無（`true` / `false`）
- `show_invalid_sunspots`: 無効黒点の初期表示状態（`true` / `false`）
- `mask_fill_color`: 塗りつぶし色（RGB、各値 0〜255）
- `mask_fill_alpha`: 不透明度（0〜255）。0 は透明、255 は不透明

設定値は最終確認ダイアログを開いたときの初期状態です。ツールバーにはチェックマーク付きの **Mask Fill** と **無効黒点** のチェックボックスを並べます。**Mask Fill** は選択領域の半透明塗りつぶしを、**無効黒点** はマスクで除外された黒点を赤色の半透明オーバーレイで、それぞれ表示／非表示に切り替えます。無効黒点の初期表示状態は `Display.show_invalid_sunspots` で設定します。
