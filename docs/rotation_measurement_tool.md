# 太陽画像 回転角測定ツール

2枚の太陽画像を読み込み、同じ黒点などの対応点から画像間の回転・倍率・平行移動を求め、透過重ね合わせで位置合わせを確認する GUI ツールです。PR #31 の観測所ごとの画像方向（`north_vector`）を確認する際の補助に使用できます。

## 起動

プロジェクトの依存パッケージをインストールした Python 環境で、プロジェクトルートから実行します。

```powershell
python run.py --rotation-tool
```

TIFF（`.tif` / `.tiff`）および FITS（`.fits` / `.fit` / `.fts`）の2次元グレースケール画像を読み込めます。元ファイルは変更しません。

## 基本操作

1. **画像 A を開く** と **画像 B を開く** から2枚を選びます。A を基準画像、B を角度測定の対象にします。
2. 画像 A で、同じ物理的特徴を示す点を2点クリックします。画像 B でも、対応する点を同じ順番で2点クリックします。黒点や安定して識別できる特徴を選びます。各画像の表示には選択順を示す番号が表示されます。
3. **4点から自動位置合わせ** を押します。B画像からA画像への回転、倍率、平行移動を2組の対応点から計算します。
4. 下側の透過重ね合わせ表示と透過率スライダーで重なりを確認します。必要に応じて「追加回転」を微調整します。回転を動かすたびにオーバーレイが更新されます。
5. **重ね合わせ画像・測定値を保存** で PNG と JSON を保存します。

対応点を指定し直す場合は、同じ画像で3点目をクリックすると、その画像の点選択が新しく始まります。**対応点をクリア** はマーカーのみを消し、現在の変換結果は保持します。**初期配置に戻す** は自動位置合わせと手動回転を解除し、画像全体を中央に配置します。

## 回転角の定義

角度の符号は画面上の画像座標（右が +X、下が +Y）を基準とし、時計回りを正とします。

- **Bに適用する総補正角**: B画像をA画像に重ねるために適用した角度です。
- **Aを基準にしたBの相対回転**: 総補正角の符号を反転した値です。例えば B が A に対して時計回りに 12° 回転している場合、B→A の補正角は -12°、相対回転は +12° になります。
- **倍率**: 対応点間の距離について「Aの距離 ÷ Bの距離」です。1より大きい場合、BはAの座標系へ変換すると拡大されます。
- **追加回転**: 自動位置合わせ後に、画像 B の中心まわりへ加える微調整角です。JSONには自動補正角・追加角・総補正角を分けて記録します。

## 保存ファイル

選択した保存先に次の2ファイルを出力します。

- `*.png`: A画像を基準に、変換したB画像を指定の透過率で重ねた画像
- `*.json`: 入力ファイル、対応点のピクセル座標、自動回転補正角、手動追加角、総補正角、相対回転角、倍率、変換行列、透過率

## 測定上の注意

- このツールが測るのは、指定した2組の対応点を結ぶ線分の方向差に基づく**画像間の相対回転**です。天文学的な北方向や絶対的な太陽北を自動推定するものではありません。
- 対応点はできるだけ離れた位置から選び、各画像で同じ物理的特徴を正確にクリックしてください。近すぎる2点ではクリック誤差が角度へ大きく影響します。
- 撮影時刻が異なる画像では、太陽自転・差動回転や黒点の変化によって対応点自体が移動します。その移動が回転角に混入するため、カメラ回転を測る場合は撮影時刻が近い画像を使い、安定して対応付けられる特徴を選んでください。
- 2組の点だけで相似変換（回転・一様倍率・平行移動）を決めます。レンズ歪み、非一様な拡大縮小、せん断、画像の反転は補正しません。鏡像の有無は別途確認してください。
- 初期表示は画像全体を中央に配置した状態です。自動位置合わせ前の追加回転は目視調整用であり、測定済みの回転角ではありません。
- PNG は各画像を個別に表示用階調へ正規化して合成します。科学解析用の元画素値や FITS/TIFF メタデータは PNG に保持されません。元画像は変更されません。

## PR #31 の設定に使う場合

このツールの相対回転角は、2つの観測画像間の向きの差を確認するための値です。`comparison.yaml` の `north_vector` は各画像の元画像座標における北方向ベクトルなので、この相対角だけから絶対的な `north_vector` を一意に決めることはできません。北方向が既知の基準画像 A を用意し、その方向を基準として比較画像 B の方向を変換してください。`flip_x`（鏡像反転）の判定も別に必要です。
