# 太陽黒点検出アプリケーション 利用説明書

## 1. 本書の目的と処理の概要

本書では、太陽黒点検出アプリケーションの実行手順、画面に表示される各ダイアログの操作方法、出力ファイルの構成と記載内容、および設定ファイルの変更方法を説明します。

本アプリケーションは、指定した太陽画像を読み込み、次の順序で処理します。

1. 入力画像の読み込み
2. 周縁減光補正[^3]
3. 画像の特徴強調
4. 黒点候補の抽出・領域分割
5. マスク[^5]領域の選択と、該当候補の除外
6. 画像・CSV・実行ログの保存
7. 設定で有効にした場合、最終結果の確認画面を表示

処理に使用した設定値や検出数は、実行ごとに作成されるログにも記録されます。画面上の表示状態と、CSV[^15]に記録される解析結果は役割が異なります。特に最終確認画面のチェックボックスは表示を切り替えるものであり、解析をやり直したり、CSVの内容を書き換えたりするものではありません。

## 2. アプリケーションの起動と入力画像の指定

### 2.1 Windows向け起動バッチ（run.bat）

Windowsでは、プロジェクトのルートフォルダーにある **run.bat** をダブルクリックするとアプリケーションを起動できます。引数を指定しない通常起動では、**.venv** フォルダーが存在すれば仮想環境を使用し、存在しなければPATH上のシステムPythonを使用します。通常起動で仮想環境を新規作成したり、依存パッケージをインストールしたりすることはありません。

仮想環境を準備する場合は、次を実行してください。

~~~bat
run.bat --setup
~~~

**--setup** は、プロジェクトのルートフォルダーに **.venv** を作成または再利用し、**pyproject.toml** の **[project].dependencies** に定義された実行時依存パッケージをインストールします。**[project.optional-dependencies].dev** に定義された開発用パッケージはインストールしません。セットアップだけを行って終了し、**run.py** は実行しません。セットアップ後は通常の **run.bat** でも自動的に **.venv** が選択されます。

システムPythonへ直接セットアップしたい場合は、次を実行してください。

~~~bat
run.bat --setup --global
~~~

**--setup --global** は、仮想環境外のPython 3.13以上を選択し、**[project].dependencies** の実行時依存パッケージをシステムPython環境へインストールします。このオプションでは **.venv** を作成・変更しません。既存の **.venv** がある場合、通常の **run.bat** は引き続き **.venv** を優先します。グローバル環境で直接起動する場合は、セットアップ時に選択したシステムPythonで **python run.py**（Python Launcherを使用する場合は **py -3 run.py**）を実行してください。**--global** は **--setup** と組み合わせた場合のみ指定できます。

#### run.batが行う処理

**通常起動（ダブルクリック、または引数なし）**

1. バッチファイル自身が置かれているプロジェクトフォルダーへ移動します。
2. **.venv** フォルダーが存在する場合は、その環境を使用します。存在しない場合はPATH上の **python** を探し、利用できなければPython Launcherの **py -3** を確認します。
3. **.venv** を使用する場合はPythonのバージョン、プロジェクト本体のインストール状態、**pip check** の結果を確認します。システムPythonを使用する場合はPythonが **3.13以上**であることを確認します。
4. 選択したPythonで **run.py** を実行します。

通常起動では、仮想環境の作成・有効化や依存パッケージのインストール・更新は行いません。システムPythonへ切り替わった場合は、その環境に必要な依存パッケージがあらかじめインストールされている必要があります。既存の **.venv** が不完全な場合は、システムPythonへ自動的に切り替えず、セットアップを案内して終了します。

**仮想環境での起動（--venv）**

1. **.venv\\Scripts\\python.exe** が存在することを確認します。
2. Pythonのバージョンが **3.13以上**であることを確認します。
3. **pyproject.toml** の **[project].name** に対応するプロジェクト本体のインストール情報が存在することを確認します。
4. **pip check** で依存パッケージの不足・バージョン不整合がないことを確認します。
5. すべての確認に通った場合だけ、仮想環境のPythonで **run.py** を実行します。

**--venv** は既存の **.venv** だけを使用します。仮想環境が存在しない場合や、プロジェクト本体・依存パッケージが不足または不整合の場合は、システムPythonへの切り替えや自動インストールを行わず、**run.bat --setup** の実行を案内して終了します。

比較モードは次の形式で起動します。

~~~bat
run.bat --compare
run.bat --compare source_input\2026-11-02
run.bat --venv --compare source_input\2026-11-02
~~~

**--compare** と任意の日付フォルダー引数は **run.py** へそのまま渡されます。日付フォルダー名は **YYYY-MM-DD** です。日付フォルダーを省略するとフォルダー選択ダイアログが開きます。`--venv` を併用すると、既存の **.venv** で比較モードを実行します。

**仮想環境の設定（--setup）**

1. 仮想環境外のPython 3.13以上をPATH上の **python**、またはPython Launcherの **py -3** から探します。
2. **.venv** がない場合は新規作成します。既存の仮想環境があれば再利用し、不完全なフォルダーだけが残っている場合は作り直します。
3. **ensurepip** でpipを利用可能な状態にします。
4. **.venv** のPythonで **python -m pip install --only-binary=scikit-image -e .** を実行します。pipが **pyproject.toml** の **[project].dependencies** を読み取り、実行時依存パッケージを導入します。
5. セットアップ結果を表示して終了します。アプリケーションは起動しません。

**システムPythonへの設定（--setup --global）**

1. 仮想環境外のPython 3.13以上をPATH上の **python**、またはPython Launcherの **py -3** から探します。
2. **ensurepip** でpipを利用可能な状態にします。
3. 選択したシステムPythonで **python -m pip install --only-binary=scikit-image -e .** を実行します。
4. **.venv** は作成・変更せず、セットアップ結果を表示して終了します。

**--setup** は初回だけでなく、仮想環境の依存パッケージを更新・修復したい場合にも使用できます。**--setup --global** はシステムPython側の実行時依存パッケージを更新したい場合に使用します。既存の **.venv** がPython 3.13未満の場合は、案内に従って **.venv** を削除してから再実行してください。

不明なオプションを指定した場合は、使用可能な形式 **run.bat [--compare [DATE_FOLDER]|--venv [--compare [DATE_FOLDER]]|--setup [--global]|--help]** が表示され、処理は開始されません。セットアップまたはアプリケーションでエラーが発生した場合は、エラー内容と終了コードを表示します。処理終了時にはキー入力待ちとなるため、表示された内容を確認してからウィンドウを閉じられます。

### 2.2 Pythonコマンドによる起動

依存パッケージがすでにインストールされている環境では、プロジェクトのルートフォルダーから次のコマンドで直接起動することもできます。

~~~text
python run.py
~~~

この方法では、**run.bat** によるPythonのバージョン確認や依存パッケージのインストールは行われません。利用するPython環境に、**pyproject.toml** に定義された依存パッケージがインストールされていることを事前に確認してください。

### 2.3 入力画像選択ダイアログ

設定ファイル **src/config.yaml** の **Paths.input_image** が **?Dialog?** の場合、起動後に「画像ファイルを選択してください」というファイル選択ダイアログが表示されます。

ファイルの種類として、次の拡張子が選択対象として表示されます。

- TIFF：**.tif**、**.tiff**
- FITS[^2]：**.fits**、**.fit**、**.fts**

「All files」を選択すると他の拡張子も一覧には表示されますが、アプリケーションが読み込みに対応している形式はTIFFとFITSです。対応外の形式を選択した場合、画像読み込み時にエラーとなります。

対象の画像を選択して開くと処理が開始されます。選択をキャンセルした場合は入力画像が確定しないため、その実行は開始されません。

毎回ファイル選択ダイアログを表示する必要がない場合は、**Paths.input_image** に画像ファイルのパスを直接記述します。相対パスはプロジェクトのルートフォルダーを基準に解決されます。

## 3. 3つのダイアログの操作方法

### 3.1 入力画像選択ダイアログ

このダイアログでは、解析対象となる画像ファイルを1つ指定します。

1. 左側のフォルダー一覧から画像の保存場所を開きます。
2. 対象のTIFFまたはFITS画像を選択します。
3. 「開く」を押して選択を確定します。

ファイル名だけでなく、選択したファイルの保存場所も確認してください。同じ名前の画像が複数のフォルダーに存在する場合、意図した画像とは異なるファイルを選択している可能性があります。

### 3.2 マスク領域選択ダイアログ（Select Mask Regions）

この画面では、黒点候補のうち解析対象から除外する範囲を矩形で指定します。画面に表示される画像は、黒点候補の抽出処理後のデータです。周縁減光補正前の元画像を表示する画面ではありません。

右側のカラーバーは、画面に表示している抽出結果の画素値[^4]の範囲を示します。上端が最大値、下端が最小値です。Watershed方式[^13]を選択している場合、表示値は領域ラベル[^6]に対応するため、太陽画像の物理的な明るさを示す目盛りではありません。

#### 範囲の指定

1. 画像上でマウスの左ボタンを押します。
2. ボタンを押したまま、除外対象を囲む位置までドラッグします。
3. ボタンを離すと矩形が確定し、画面下部の「選択領域」の数が更新されます。
4. 必要に応じて、同じ操作を繰り返して複数の矩形を指定します。
5. 範囲を確認し、「確定」を押します。

矩形は複数指定できます。各矩形は、画像上で除外したい範囲を囲むように指定してください。矩形の一部に触れた黒点候補は、その候補全体が除外対象になります。矩形の境界で黒点候補を切り取って、残りの部分だけを検出対象として残す処理ではありません。

#### 画面内の表示

| 表示 | 意味 |
| --- | --- |
| Cursor: x, y | カーソル位置の画像座標です。 |
| Image: 幅 x 高さ | 読み込んだ画像の画素数[^1]です。 |
| Last ROI[^5] | 直前に指定した矩形の左上座標と幅・高さです。 |
| Selection | 矩形をドラッグしている間に表示される選択範囲です。 |
| Display scale | 画面上の表示倍率です。画像データの拡大・縮小や解析精度を変更する値ではありません。 |
| 選択領域 | 現在指定されている矩形の数です。 |
| カラーバー | 表示中の抽出結果の値と色の対応を示します。 |

#### 取り消し・確定・キャンセル

| 操作 | 動作 |
| --- | --- |
| 「1つ戻す」 | 最後に追加した矩形を1つ取り消します。 |
| Backspace / Delete | 最後に追加した矩形を1つ取り消します。 |
| Enter / Esc | 現在の矩形選択を確定して画面を閉じます。 |
| 「確定」 | 現在の矩形選択を確定します。 |
| 「キャンセル」 | 現在の矩形選択を破棄し、マスク領域なしとして処理を続けます。 |

「キャンセル」はアプリケーション全体の実行を中止する操作ではありません。マスク領域を指定せずに処理を続ける場合に使用できます。矩形を1つも指定せずに確定した場合も、マスクによる候補の除外は行われません。

指定した矩形の座標と大きさは、実行ログにも記録されます。座標の原点は画像の左上で、Xは右方向、Yは下方向に増加します。

### 3.3 最終結果確認ダイアログ（Final Result Preview）

**Display.show_final_image** を **true** に設定すると、処理後に最終結果確認ダイアログが表示されます。**false** の場合、この画面は表示されませんが、画像やCSVなどの出力処理は実行されます。

この画面では、マスク適用後の解析画像を拡大・縮小しながら確認できます。選択したマスク範囲や、マスクによって除外された黒点候補を重ねて表示することもできます。

#### 上部ツールバー

| 操作 | 動作 |
| --- | --- |
| Home | 画像全体が表示される初期表示範囲に戻します。Homeキーでも同じ操作ができます。 |
| Back | 直前の表示範囲に戻します。戻る履歴がない場合は使用できません。 |
| Forward | Backで戻った後、次の表示範囲に進みます。進む履歴がない場合は使用できません。 |
| Pan | 選択後、画像上をマウスの左ボタンでドラッグすると表示位置を移動します。 |
| Zoom | 選択後、画像上をマウスの左ボタンでドラッグして矩形範囲を指定すると、その範囲を拡大表示します。 |
| Ctrl + マウスホイール | カーソル位置を中心として拡大・縮小します。PanまたはZoomの選択状態にかかわらず使用できます。 |
| Shift + 右ドラッグ | Panを選択していない場合でも、画像の表示位置を移動します。 |

PanとZoomは、選択したモードに応じて左ドラッグの動作を切り替えます。拡大した範囲から元の表示へ戻る場合はHome、直前の表示へ戻る場合はBackを使用します。

#### 表示切り替え

| チェックボックス | 表示内容 |
| --- | --- |
| Mask Fill | マスク選択画面で指定した矩形を半透明で塗りつぶします。初期状態は **Display.show_mask_fill** で設定します。 |
| 無効黒点 | 通常maskまたはRmaskによって除外された黒点候補を赤色のオーバーレイで表示します。初期状態は **Display.show_invalid_sunspots** で設定します。 |

これらのチェックボックスは、確認画面上の表示だけを切り替えます。チェックを外しても除外された黒点が復元されることはなく、チェックを付けても追加で黒点が除外されることはありません。また、「無効黒点」の表示対象は通常maskまたはRmaskによって除外された候補です。最小面積の条件によって除外された候補を表示する機能ではありません。

Mask Fillの色と不透明度は、**Display.mask_fill_color** と **Display.mask_fill_alpha** で変更できます。

#### 画面下部の情報と終了

- **Cursor: x, y**：カーソル位置の画像座標です。画像の外側にカーソルがある場合は座標が「—」で表示されます。
- **X / Y**：現在画面に表示している画像座標の範囲です。拡大・縮小や移動に応じて値が変わります。
- **カラーバー**：最終確認画面に表示している画像の表示階調を示します。画面表示用に0～255の範囲へ変換された値であり、元のTIFF/FITS画像の画素値そのものを示すものではありません。
- **Close**：最終結果確認画面を閉じます。画面を閉じると処理が終了します。

## 4. 出力先とファイル構成

### 4.1 セッションフォルダー

出力先は **src/config.yaml** の **Paths.output_folder** で指定します。初期設定は **.\\results** です。相対パスを指定した場合は、プロジェクトのルートフォルダーを基準に保存されます。

アプリケーションを1回実行するごとに、出力先の中へ新しいセッション[^21]フォルダーが作成されます。フォルダー名には実行日時と識別用の数字が含まれます。同じフォルダーに別の実行結果が上書きされないよう、実行単位で分けて保存します。

初期設定でWatershed方式、Black Top-Hat方式を使用した場合の構成例を示します。ファイル名中の数値は、実際に使用した設定値に応じて変わります。

~~~text
results/
└─ session_YYYYMMDD_HHMMSS_xxxxxx/
   ├─ polynomialFit_alpha0.85_boost1.1.png
   ├─ BlackTopHat_kernel15.png
   ├─ BlackTopHat_kernel15_masked.png
   ├─ watershed_c1_threshold1000_minArea2_minDistance5.png
   ├─ sunspot_statistics.csv
   ├─ sunspot_exclusion_list.csv
   ├─ img00000001_summary.png
   ├─ run_YYYYMMDD_HHMMSS_xxxxxx.log
   └─ run_YYYYMMDD_HHMMSS_xxxxxx.json
~~~

上記の例では、入力ファイル名が **img00000001.tiff** であるため、サマリー画像名は **img00000001_summary.png** になります。選択する強調処理や抽出方式によって画像ファイル名は変わります。すべてのファイルはセッションフォルダー直下に保存され、セッション内に用途別のサブフォルダーは作成されません。

### 4.2 画像ファイル

| ファイル名の例 | 内容 |
| --- | --- |
| **polynomialFit_alpha0.85_boost1.1.png** | 周縁減光補正後の画像です。alphaとbrightness_boostの値がファイル名に含まれます。 |
| **BlackTopHat_kernel15.png** | 選択した方式による特徴強調後の画像です。Black Top-Hat方式の場合はカーネルサイズがファイル名に含まれます。 |
| **BlackTopHat_kernel15_masked.png** | マスク領域内の画素値を0にした強調画像です。マスク適用前の強調画像とは別ファイルとして保存されます。 |
| **watershed_c1_threshold1000_minArea2_minDistance5.png** | 黒点候補の抽出結果画像です。抽出方式と、その方式で使用した主な設定値がファイル名に含まれます。 |
| **img00000001_summary.png** | 入力画像、周縁減光補正後、特徴強調後、二値画像の4段階をまとめた処理結果レポートです。入力ファイル名を基に作成されます。 |

強調処理のファイル名は、選択方式に応じて次のように変わります。

| 強調方式 | 出力ファイル名 |
| --- | --- |
| SobelFilter | **SobelFilter_kernel{kernelSize}.png** |
| BlackTopHat | **BlackTopHat_kernel{kernelSize}.png** |
| GaussianFilter | **GaussianFilter_sigma{sigmaSize}.png** |

抽出結果画像のファイル名は、抽出方式が **countComponents** の場合は **countComponents_c{c}_threshold{space_threshold}_minArea{min_area}.png**、**watershed** の場合は **watershed_c{c}_threshold{space_threshold}_minArea{min_area}_minDistance{min_distance}.png** となります。

サマリー画像には、入力ファイル名、生成日時、検出数、Pathsを除く設定値、および4段階の画像が表示されます。画像処理の各段階で結果がどのように変化したかを比較するときに使用します。

### 4.3 黒点統計CSV（sunspot_statistics.csv）

このCSV[^15]には、抽出後にマスクによる除外を受けず、最終結果に残った黒点候補が1行につき1件記録されます。ファイルはUTF-8 BOM付きで保存されます。Excelなどで開く場合は、文字コードをUTF-8として読み込んでください。

| 列名 | 内容 |
| --- | --- |
| **sunspot_id** | CSV内での通し番号です。1から始まります。別のCSVの番号とは対応しません。 |
| **label**[^6] | 画像処理で各候補領域に割り当てられた識別番号です。同じ実行内で除外一覧と照合するときに使用します。 |
| **centroid_x_px** | 黒点候補を構成する画素のX座標の平均値です。 |
| **centroid_y_px** | 黒点候補を構成する画素のY座標の平均値です。 |
| **bbox_x_px** | 候補領域を囲む矩形の左上X座標です。 |
| **bbox_y_px** | 候補領域を囲む矩形の左上Y座標です。 |
| **bbox_width_px** | 候補領域を囲む矩形の幅です。 |
| **bbox_height_px** | 候補領域を囲む矩形の高さです。 |
| **area_px** | 黒点候補を構成する画素数です。 |

### 4.4 黒点除外一覧CSV（sunspot_exclusion_list.csv）

このCSVには、マスク領域または最小面積フィルターによって除外された黒点候補が1行につき1件記録されます。位置や大きさを示す列は、黒点統計CSVと同じ意味です。

| 列名 | 内容 |
| --- | --- |
| **sunspot_id** | 除外一覧CSV内での通し番号です。黒点統計CSVの番号とは対応しません。 |
| **label** | 除外された候補の識別番号です。 |
| **centroid_x_px / centroid_y_px**[^14] | 候補領域を構成する画素の平均座標です。 |
| **bbox_x_px / bbox_y_px** | 候補領域を囲む矩形の左上座標です。 |
| **bbox_width_px / bbox_height_px** | 候補領域を囲む矩形の幅と高さです。 |
| **area_px** | 除外された候補を構成する画素数です。 |
| **excluded_by_factor** | 除外要因です。マスクによる除外は **mask**、最小面積による除外は **minArea** です。 |
| **exclusion_stage** | 除外された処理段階です。**mask**、**connected_components**、**watershed** のいずれかです。 |
| **min_area_threshold_px** | 最小面積フィルターのしきい値[^8]です。マスクによる除外の場合は空欄です。 |
| **excluded_by_mask_ids** | 除外に関係したマスク番号です。複数ある場合はセミコロン区切りで記録されます。 |
| **excluded_by_mask_regions** | マスク領域の番号、座標、幅、高さを格納したJSON[^16]配列です。マスク以外の除外では空欄です。 |

マスク番号は、マスク選択画面で矩形を指定した順番に対応する1始まりの番号です。1つの候補が複数の矩形と重なっていた場合、該当するすべてのマスク番号と領域情報が記録されます。

**excluded_by_factor** が **mask** の場合は、**excluded_by_mask_ids** と **excluded_by_mask_regions** で該当範囲を確認します。**minArea** の場合は、**area_px** が **min_area_threshold_px** 未満であることを確認します。

### 4.5 座標と面積の読み方

CSVの座標はすべて、画像の左上を原点とする0始まりのピクセル座標です。Xは右方向、Yは下方向に増加します。

- **重心（centroid）**：黒点候補を構成する画素のX座標・Y座標それぞれの平均です。小数点以下6桁で記録されます。
- **外接矩形（bbox）**：黒点候補を囲む最小の矩形です。**bbox_x_px** と **bbox_y_px** が左上、**bbox_width_px** と **bbox_height_px** が幅と高さです。幅と高さには両端の画素を含みます。
- **画素面積（area_px）**：黒点候補を構成する画素数です。外接矩形の面積（幅×高さ）とは異なります。

**sunspot_id** はCSV内だけで使う通し番号です。2つのCSVの行を対応させる場合は **label** を確認してください。ただし、labelは処理段階ごとに付け直される場合があるため、異なる **exclusion_stage** 間で番号だけを比較しないでください。また、異なる実行セッション間で同じ黒点を表す識別子ではありません。

### 4.6 実行ログ（.log）

**run_日時.log** は、人が内容を確認するためのテキスト形式のログです。主な記録は次のとおりです。

- 実行開始・終了時刻、実行ID、セッションフォルダー
- 実際に使用した解析方式とパラメータ
- 入力画像のファイルパス、画像サイズ、配列のデータ型
- 周縁減光補正で推定された太陽の中心・半径
- 黒点候補の抽出時に使用したしきい値、候補数、除外数
- マスク領域の座標と大きさ、マスク適用前後の候補数
- CSVや画像の保存先、最終的な検出数、処理時間
- エラーが発生した場合の例外情報とスタックトレース

ログの各行は、日時、ログレベル、記録元、メッセージの順に表示されます。**INFO** は処理の進行状況や集計情報、**WARNING** は警告、**ERROR** はエラーを示します。これらはログレベル[^18]です。詳細な候補情報などの **DEBUG** ログはファイルに記録されますが、ターミナルには表示されません。

### 4.7 実行ログ（.json）

**run_日時.json** は、実行情報を項目ごとに整理したJSON[^16]形式のログです。テキストとして読むほか、プログラムから実行情報を取り出す場合にも使用できます。

| 主な項目 | 内容 |
| --- | --- |
| **run_id** | 実行を識別するIDです。 |
| **status** | 実行状態です。実行中、成功、失敗などを表します。 |
| **started_at / finished_at** | 実行開始時刻と終了時刻です。 |
| **duration_seconds** | 処理に要した時間（秒）です。 |
| **execution** | 実行スクリプト、設定ファイル、引数、作業ディレクトリ、プロセスIDなどです。 |
| **environment** | OS、CPUアーキテクチャ、Python、主要パッケージなどの実行環境情報です。 |
| **output** | 出力先とセッションフォルダーの情報です。 |
| **config** | 実行時に使用した設定値です。 |
| **events** | 入力画像メタデータ、マスク領域の選択・適用、CSV出力などのイベント履歴です。 |
| **result** | 正常終了時の検出数などの結果です。 |
| **error** | 失敗時の例外の種類、メッセージ、スタックトレースなどです。 |

入力画像のメタデータ[^17]は **input_image_metadata** イベントとして記録されます。ファイルの基本情報や画像配列の形状・データ型に加え、TIFFまたはFITSに含まれるメタデータが取得可能な範囲で保存されます。画像の画素データそのものをJSONログに保存するものではありません。

設定値や引数にパスワード、トークン、シークレットなどに該当する値が含まれる場合、ログ出力時にマスキングされます。環境変数の値は記録されません。

## 5. 設定ファイルの変更方法

### 5.1 設定ファイルの場所と編集方法

設定ファイルは **src/config.yaml** です。テキストエディターで開き、変更したい項目の値を編集して保存します。設定ファイルはYAML[^19]形式のため、次の点に注意してください。

- 項目名と値の間にはコロンを使用します。
- 階層はスペースによる字下げで表します。タブ文字は使用しないでください。
- 文字列は必要に応じて引用符で囲みます。
- 数値は、文字列にせず数値として記述します。
- **chosen_method** を変更する場合は、対応する方式の設定ブロックが存在することを確認してください。

設定は次回の実行から反映されます。実行中に設定ファイルを書き換えても、すでに開始した実行の設定は変更されません。実際に使用された値は、セッションフォルダー内のログとサマリー画像で確認できます。

### 5.2 入出力先（Paths）

| 設定項目 | 初期値 | 意味 |
| --- | --- | --- |
| **Paths.input_image** | **?Dialog?** | 入力画像のパスです。**?Dialog?** の場合は起動時にファイル選択ダイアログを表示します。 |
| **Paths.output_folder** | **.\\results** | セッションフォルダーを作成する出力先です。 |

### 5.3 周縁減光補正（LimbDarkingResolution）

**chosen_method** で補正方式を指定します。現在のメイン処理で使用できる方式は **polynomialFit** です。

| 設定項目 | 初期値 | 意味 |
| --- | --- | --- |
| **LimbDarkingResolution.chosen_method** | **polynomialFit** | 使用する周縁減光補正方式です。 |
| **polynomialFit.alpha** | **0.85** | 補正前画像と補正後画像を混ぜ合わせる割合です。0に近づけると補正前画像の割合が大きくなり、1に近づけると補正後画像の割合が大きくなります。 |
| **polynomialFit.brightness_boost** | **1.1** | 補正後の明るさに掛ける倍率です。1.0は倍率変更なし、1.1は約1.1倍です。出力値は画像のデータ型の範囲内に収められます。 |

### 5.4 特徴強調（Emphasis）

**chosen_method** で、黒点候補を抽出しやすくするために使用する強調方式を選択します。現在選択できる方式は **SobelFilter**[^10]、**BlackTopHat**[^11]、**GaussianFilter**[^12] です。

| 設定項目 | 初期値 | 意味 |
| --- | --- | --- |
| **Emphasis.chosen_method** | **BlackTopHat** | 使用する強調方式です。 |
| **SobelFilter.kernelSize** | **3** | Sobelフィルターで微分を計算する近傍のサイズです。大きさを変更すると輪郭・明るさの変化に対する応答が変わります。 |
| **BlackTopHat.kernelSize** | **15** | Black Top-Hat変換で使用する楕円形の構造要素のサイズです。値を大きくすると、より広い近傍を基準に暗い特徴を抽出します。 |
| **GaussianFilter.sigmaSize** | **20** | 背景を平滑化するガウシアンフィルターのシグマ値です。平滑化した背景を入力画像から差し引きます。値を大きくすると、より広い範囲の明るさ変化を背景として扱います。 |

選択していない方式の設定値は、現在の実行では使用されません。方式を変更するときは、該当方式の設定ブロックにある値を調整してください。

### 5.5 黒点候補抽出（Extraction）

**chosen_method** で **countComponents** または **watershed** を選択します。

**countComponents** は、しきい値[^8]を用いて候補画素を抽出し、隣接する候補画素を連結成分[^7]として数える方式です。**watershed** は、同じ候補抽出の後、候補領域をさらに分割して数える方式です。

| 設定項目 | 初期値 | 意味 |
| --- | --- | --- |
| **Extraction.chosen_method** | **watershed** | 使用する抽出方式です。 |
| **countComponents.c** | **1** | 太陽領域の画素値の平均値と標準偏差[^9]から、候補抽出のしきい値を計算する係数です。しきい値は平均値 + c × 標準偏差です。大きくするとしきい値が高くなり、候補画素が少なくなる傾向があります。 |
| **countComponents.space_threshold** | **1000** | 太陽領域と背景を区別する画素値のしきい値です。この値より大きい画素を太陽領域の統計計算に使用します。 |
| **countComponents.min_area** | **2** | 候補領域として残す最小画素数です。この値より小さい領域は除外されます。Watershed方式では、初期候補の抽出時と領域分割後の両方で使用されます。 |
| **watershed.min_distance** | **5** | Watershed方式で分割の基準となるマーカー同士に確保する最小距離です。小さくすると近い位置にもマーカーが作られやすくなり、大きくするとマーカー数が減る傾向があります。 |

抽出結果は入力画像や前段階の強調方法の影響を受けます。パラメータを変更した場合は、最終検出数だけで判断せず、抽出結果画像・サマリー画像・除外一覧CSVも併せて確認してください。

### 5.6 マスク除外判定（Mask）

通常の矩形maskと、MIN2が推定した太陽中心・半径に基づく円形のRmaskを設定します。両方のマスクに同じ境界判定方式を適用します。

| 設定項目 | 初期値 | 意味 |
| --- | --- | --- |
| **Mask.boundary_policy** | **overlap** | 境界にかかる黒点の扱いです。**overlap** は除外領域に1画素でも入った黒点を除外し、**centroid** は重心が除外領域内にある黒点を除外し、**contained** は黒点の全画素が一つの除外領域に収まる場合だけ除外します。 |
| **Mask.Rmask.enabled** | **false** | trueにすると、MIN2で取得した太陽中心から外側にある黒点を半径マスクで除外します。 |
| **Mask.Rmask.radius_ratio** | **0.85** | 太陽半径に対するRmaskの境界位置です。0.85の場合、中心から太陽半径の85%以上離れた黒点が除外対象になります。正の有限値を指定でき、1を超える値も使用できます。 |

**overlap** は従来の矩形maskと同じ判定です。たとえば黒点が矩形maskの境界に少しでも重なる場合や、Rmaskの境界円をまたいで外側に画素がある場合は除外されます。**centroid** は黒点の重心位置で判定し、**contained** は通常maskでは選択したすべての矩形領域の和集合に黒点の全画素が含まれる場合に除外します。黒点が複数の矩形領域にまたがっていても、領域外に画素がなければ除外対象です。Rmaskでは黒点の全画素が境界円の外側にある場合だけ除外します。

通常maskとRmaskの両方に該当した黒点は、検出数からは1個として除外し、除外一覧CSVの `excluded_by_factor` には両方の要因を記録します。Rmaskの除外結果には、MIN2の中心座標・推定半径比・境界距離がCSVと実行ログに保存されます。

## 6. 実行ログの確認例

ターミナルには、処理の進行状況と集計情報が表示されます。提供された実行ログでは、次のような項目が確認できます。

~~~text
2026-11-03 00:27:51 | INFO | sunspot.main | Input image: ...img00000001.tiff
2026-11-03 00:27:51 | INFO | sunspot.main | Loaded image: shape=(1104, 1608), dtype=uint16
2026-11-03 00:28:08 | INFO | sunspot.mask | マスク領域 1: x=544, y=364, width=625, height=331
2026-11-03 00:28:09 | INFO | sunspot.mask | 除外した黒点数: 69
2026-11-03 00:28:09 | INFO | sunspot.mask | マスク適用後の黒点数: 62
2026-11-03 00:28:35 | INFO | sunspot.main | Processing completed: 62 sunspots detected
~~~

この例では、画像サイズが幅1608画素・高さ1104画素で、16ビット整数型の画像として読み込まれています。矩形マスクは左上座標(544, 364)、幅625画素、高さ331画素です。マスク処理では69個の候補が除外され、マスク適用後の検出数は62個と記録されています。これらは提供された実行例の値であり、入力画像や設定値が異なる場合は変化します。

解析パラメータは、ターミナルおよびログ内の **Analysis Parameters** に、周縁減光補正・強調処理・黒点候補抽出の区分ごとに表示されます。各区分は空行で分けられ、**method** は選択された処理方式、その下の項目はその方式で使用するパラメータです。

## 7. 用語の脚注

[^1]: **画素（pixel）**：デジタル画像を構成する最小単位です。画像の幅・高さやCSVの座標・面積は、画素を単位として表します。
[^2]: **TIFF / FITS**：画像データを保存するファイル形式です。FITSは天文分野で広く用いられ、画像に関するヘッダー情報を保持できます。
[^3]: **周縁減光**：太陽の画像で、中心部に比べて周辺部が暗く写る現象です。周縁減光補正は、この明るさの偏りを補正する処理です。
[^4]: **画素値**：各画素が持つ数値です。画像の明るさや、画像処理の途中で計算された値を表します。
[^5]: **マスク / ROI**：解析から除外する範囲を指定する仕組みです。ROIは「関心領域」を意味し、本書では矩形で指定した範囲を指します。
[^6]: **領域ラベル（label）**：画像内の候補領域を区別するために付ける整数の識別番号です。
[^7]: **連結成分**：隣り合う候補画素がつながってできた一まとまりの領域です。
[^8]: **しきい値（threshold）**：画素を対象に含めるかどうかを分ける境界となる数値です。
[^9]: **標準偏差**：数値のばらつきの大きさを表す統計量です。候補抽出では、太陽領域の画素値の平均値と組み合わせてしきい値を計算します。
[^10]: **Sobelフィルター**：画像の横方向・縦方向の変化を計算し、輪郭や明るさの変化を強調する画像処理です。
[^11]: **Black Top-Hat変換**：周囲より暗い局所的な特徴を抽出する形態学的な画像処理です。構造要素の大きさが、比較する近傍の範囲に関係します。
[^12]: **ガウシアンフィルター / シグマ**：画像を滑らかにする処理と、その平滑化の広がりを指定する値です。本アプリケーションでは平滑化した背景を入力画像から差し引きます。
[^13]: **Watershed / マーカー**：候補領域の内部に分割の起点となる位置を置き、その位置を基に領域を分ける手法です。マーカー間の最小距離は、分割の細かさに影響します。
[^14]: **重心（centroid）/ 外接矩形（bbox）**：重心は候補領域の画素座標の平均位置です。外接矩形は候補領域全体を囲む最小の矩形です。
[^15]: **CSV**：表形式のデータを、カンマ区切りのテキストとして保存する形式です。
[^16]: **JSON**：項目名と値を対応付けて、階層構造を持つデータを保存する形式です。
[^17]: **メタデータ**：画像ファイルや実行環境など、画素データそのもの以外の付随情報です。
[^18]: **ログレベル（INFO / WARNING / ERROR / DEBUG）**：ログの重要度を示す区分です。INFOは進行状況、WARNINGは警告、ERRORはエラー、DEBUGは詳細な調査情報を表します。
[^19]: **YAML**：設定ファイルなどに使われるテキスト形式です。字下げによって項目の階層を表します。
[^20]: **カラーマップ**：数値の大小を色の違いに置き換えて表示する方法です。カラーマップの変更は表示方法だけに影響します。
[^21]: **セッション**：アプリケーションを1回実行した単位です。出力ファイルとログは、その実行に対応するセッションフォルダーにまとめられます。
[^22]: **編集可能インストール（-e）**：開発用のインストール方式です。プロジェクトのソースを通常のパッケージコピーとして固定せず、作業フォルダー上の内容を参照する形でインストールします。

## 比較モード

同じ日付に撮影された最大4観測所の画像を比較する機能では、4画像のマスク範囲をリアルタイム同期し、解析段階別の比較画像、画像座標・共通座標別のCSV、および観測所間の黒点対応IDを出力します。実行方法と対応付けの注意点は、[比較モード利用マニュアル](comparison_mode_manual.md) を参照してください。単一画像モードは従来どおり `python run.py` または `run.bat` で実行できます。
